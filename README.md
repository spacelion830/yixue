# 易学斋 · 周易六爻 + 小六壬

把原来两个独立的单页应用合并成一个站点：统一导航、统一视觉、统一的记录系统。

- 原 `zhouyi-app/`（周易六爻起卦）
- 原 `xiaoliuren/`（小六壬起课）

两个原目录保留未动，作为对照存档；本目录是合并后的正式版本。

## 打开方式

直接用浏览器打开 `index.html` 即可（纯静态，无需服务器、无需联网）：

- 手机：把整个 `yixue` 文件夹拷到手机，用浏览器打开 `index.html`；
- 电脑：双击 `index.html`；
- 部署：整个文件夹丢到 GitHub Pages / 任意静态托管，或用 `npx serve yixue` 本地预览。

`file://` 下也能正常工作，因为所有资源都是相对路径、没有网络请求。

## 相比原来的两个单页

**合并层面**

- 统一顶部导航（首页 / 周易六爻 / 小六壬），当前页高亮；
- 统一设计令牌：宣纸底色、朱砂（周易）与青玉（小六壬）两套强调色；
- 暗色模式，跟随系统并记住选择；
- 统一页脚与免责声明、回到顶部、打印样式；
- 手机优先：`viewport-fit=cover`、安全区适配、430px 以下专门微调。

**功能增强**

| 功能 | 周易六爻 | 小六壬 |
| --- | --- | --- |
| 随机模拟（不方便掷币时） | ✅ | — |
| 用当前时间一键起课 | — | ✅ |
| 保存记录到本机 | ✅ | ✅ |
| 复制全文 / 打印 | ✅ | ✅ |
| 从首页点记录回看 | ✅ | ✅ |
| 重新起卦 | ✅ | — |

记录存在 `localStorage`（键名 `yixue.history.v1`，最多 80 条），不上传、不同步；
清空浏览器数据会一起清空，首页提供「清空本机记录」。

## 自检

```bash
node build/audit.mjs
```

检查项：页面引用的 id 是否都存在、外链资源是否齐全、JS 生成的 class 是否都有样式、
小六壬算法与手册示例是否一致（农历六月初九酉时 → 空亡·留连·小吉；532 → 小吉·大安·留连；
17:17 → 赤口·赤口·小吉）、六十四卦数据与装卦数据是否完整。

`build/extract-apps.mjs` 是当初从两个原页面抽取内联脚本的工具，改动原页面后可重跑。

## 已知取舍

- 六爻录入仍按「背面为阳」的默认口径，页面已注明可自定义但需前后一致；
- 记录只存摘要 + 六爻/三宫数据，不存整段卦辞，回看时重新渲染；
- 两个原目录与本目录数据有重复（`data/*.js` 是拷贝），改数据时以本目录为准。

## 部署到 GitHub Pages

站点是纯静态、全相对路径，仓库根目录放这些文件即可，不需要构建、不需要 Jekyll（已放 `.nojekyll`）。

### 方式 A：网页上传（最简单，不用装 git）

1. GitHub 右上角 **+ → New repository**，名字例如 `yixue`，选 **Public**，不要勾初始化 README；
2. 进入仓库 → **Add file → Upload files**；
3. 把 `yixue` 文件夹**里面的东西**全选拖进去（`index.html`、`css/`、`js/`、`data/`、`assets/`、`manuals/`、`README.md`、`manifest.webmanifest`、`.nojekyll`）。
   注意是拖「里面的内容」，不是把 `yixue` 这个文件夹本身拖进去，否则 `index.html` 会多一层目录；
4. 点 **Commit changes**；
5. 仓库 **Settings → Pages** → Source 选 **Deploy from a branch**，Branch 选 `main` + `/ (root)`，Save；
6. 等 1–2 分钟，访问 `https://<你的用户名>.github.io/yixue/`。

### 方式 B：命令行

```bash
cd yixue
git init
git add .
git commit -m "易学斋：周易六爻与小六壬"
git branch -M main
git remote add origin https://github.com/<你的用户名>/yixue.git
git push -u origin main
```

推送后在 **Settings → Pages** 里按上面第 5 步开启即可。之后每次改完 `git add . && git commit -m "update" && git push`，Pages 会自动重新发布。

### 注意事项

- 免费账户的 Pages 要求仓库 **Public**；私有仓库需要付费计划；
- 中文文件名（`manuals/小六壬零基础学习手册.docx`）能正常下载，URL 里会显示成 `%E5%B0%8F...` 编码，属正常现象；
- 站点无后端，记录存在**访问者自己的浏览器**里，换设备或清缓存就没了；
- 想本地预览：`python -m http.server 8000` 后打开 `http://localhost:8000`，或 `npx serve .`。
